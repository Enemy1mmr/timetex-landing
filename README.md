# TimeTex — шторы, тюль и карнизы оптом

[![Сайт](https://img.shields.io/badge/сайт-timetex--opt.ru-d3a53a?style=flat-square)](https://timetex-opt.ru)

**[timetex-opt.ru](https://timetex-opt.ru)** — оптовая продажа штор, тюля и карнизов
для салонов, дизайн-студий и розничных сетей. Офисы и склады в Сочи, Краснодаре,
Ростове-на-Дону и Пятигорске.

## Что здесь лежит

Репозиторий — опубликованная статическая сборка лендинга (Vite + React):

- `index.html` — оболочка с пререндеренным HTML, мета-тегами, Open Graph и JSON-LD;
- `assets/` — собранные JS и CSS;
- иконки, `site.webmanifest`, `robots.txt`, `sitemap.xml`;
- файлы подтверждения прав Яндекс.Вебмастера и Google Search Console.

## Публикация

Сайт размещён на хостинге reg.ru (FTP, корень `/www/timetex-opt.ru`), домен
обслуживается DNS-серверами reg.ru. GitHub Pages больше не используется —
репозиторий остаётся публичным архивом сборки.
